# Hints

Stuck finding a problem statement? The organizers will periodically release hints here.

## Hint Release 1
- **General**: FieldNotes seems to have many experimental modules. Check the `CHANGELOG.md` to see what has been recently added or removed.
- **General**: The `CONTRIBUTING.md` file points to specific files for new contributors. Those files might contain more than just code.

## Hint Release 2
- **General**: Sometimes, clues are left behind in the configuration files (`config/`).
- **General**: Look closely at the `README.md` and the `docs/index.md` for references to other documents or setups.

## Hint Release 3 (Final)
- **General**: Not all information is in the files on the `main` branch. Some information might be in other branches, GitHub Issues, Pull Requests, or Release notes.
- **Specific**: Read the comments in `src/main.py` and `src/utils.py` very carefully.
