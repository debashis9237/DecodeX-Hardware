# FieldNotes

FieldNotes is an open-source project to organize field observations, local reports, notes, and small datasets. It is designed for researchers, field agents, and hobbyists who need a lightweight tracking system.

## Features
- Easy data entry
- Support for multiple experimental modules
- Extensible architecture

Welcome to FieldNotes! We have several experimental modules. Look through the `CHANGELOG.md` to see recent additions. We are working on accessibility! Check our contributing guidelines for how to help.
